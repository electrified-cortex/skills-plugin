# github/pr

## pr

When routing any pull request operation -- inspect inline, or dispatch to create, review, comments, inline-comment, merge, or file-viewed.

## comments

When adding, editing, deleting, or listing PR-level comments.

## create

When opening a new pull request or draft PR via CLI.

## file-viewed

When marking or unmarking individual PR files as reviewed.

## inline-comment

When posting, editing, or deleting inline code review comments on diff lines.

## merge

When merging, closing, or reverting a pull request.

## review

When approving a PR, requesting changes, or dismissing a review.

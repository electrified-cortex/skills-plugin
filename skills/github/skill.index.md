# github

## github

When routing any GitHub operation to the correct sub-skill -- actions, API, issues, PRs, releases, repos, or setup.

## actions

When triggering, monitoring, or managing GitHub Actions workflows via CLI.

## api

When making authenticated REST or GraphQL calls to the GitHub API with no dedicated gh subcommand.

## issues

When managing the full GitHub issue lifecycle -- create, list, edit, comment, close.

## pr

When managing pull requests -- create, review, comment, merge, or mark files viewed.

## projects

When managing GitHub Projects v2 boards, items, and fields via CLI.

## release

When creating, publishing, or managing GitHub releases and release assets.

## repo

When creating, cloning, forking, or managing GitHub repositories.

## setup

When installing, authenticating, or configuring the GitHub CLI for the first time.

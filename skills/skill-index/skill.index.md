# skill-index

All sub-skills operate on an indexed skill tree. Use `finding` first when you know the skill name.

## skill-index

When an agent needs to discover available skills or select the right sub-skill for indexing work.

## auditing

When the agent suspects an index is stale, malformed, or wants to verify cascade health.

## building

When adding or removing skills from a tree, or after changes that make index files out of date.

## crawling

When the agent has a stated need and wants to find the matching skill by navigating an index cascade.

## finding

When the agent knows the skill name or purpose and wants its file path immediately -- fastest lookup path, Haiku tier.

## integration

When setting up a new agent context that needs on-demand skill discovery wired in for the first time.

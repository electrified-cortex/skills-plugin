# hash-record

## hash-record

When caching or retrieving audit, review, or hygiene results by content hash.

## check

When probing the cache for a single file to get HIT or MISS before doing work.

## index

When building or refreshing the manifest index inside the hash-record store.

## manifest

When computing a combined cache key for a set of files together.

## prune

When cleaning up orphaned hash directories from the store.

## rekey

When a file's content has changed and its hash-record entry needs to move to the new hash path.
